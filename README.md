# Basis Design for Electronic Structure and Beyond

This repository contains the latest author-maintained version (`thesis.pdf`) of the PhD thesis titled "Basis Design for Electronic Structure and Beyond," which is available through [the Dartmouth Digital Commons (DDC)](https://digitalcommons.dartmouth.edu/dissertations/464/). The DDC version (v1.0.0) should be regarded as the official archived version for potential citations. This version is only maintained to further correct typographical errors and other minor editorial issues for personal reference. No substantive changes to the scientific content, results, or conclusions are intended. Copyright of this version is also held by the author (Weishi Wang).

## Formatting Style of the Thesis

The formatting of the generated thesis is largely based on the [LaTeX template (the latest version as of October 5th, 2021)](https://www.overleaf.com/latex/templates/dartmouth-phd-thesis/hdztkxftnsmd) by David Freund, Daryl DeFord, and Marek Svoboda, to comply with the thesis guidelines of the Guarini School of Graduate and Advanced Studies at Dartmouth College.
